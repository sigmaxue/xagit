1. INTRO						*xagit-intro*

xagit is a Magit-style git TUI written in Rust:
    https://github.com/sigmaxue/xagit

This plugin opens xagit in a floating window, so you can stage, commit,
rebase, ... without leaving the editor. It supports both editors with the
same command and the same |xagit-config| options:

  Vim 8.2+/9.x   a |popup| running a hidden |terminal| (popup-terminal)
  Neovim 0.5+    a |nvim_open_win()| float running via |termopen()|

When xagit exits (C-x C-c) the floating window closes and you are back in
your buffer. xagit always occupies the whole float and keeps keyboard focus
until it exits. A second :Xagit reuses the running float instead of erroring.

==============================================================================
2. REQUIREMENTS					*xagit-requirements*

- Vim 8.2+ / 9.x with +terminal and +popupwin, OR Neovim 0.5+ (with
  nvim_open_win() and termopen()). Check with:
    :echo has('nvim') || (has('terminal') && has('popupwin'))
- A terminal that understands cursor movement / colors. Set 'term' to a
  sensible value (e.g. xterm-256color).
- The xagit executable. Install it into $PATH, or point |g:xagit_cmd| at
  the built binary:
    let g:xagit_cmd = '/path/to/xagit/target/release/xagit'
  The plugin also auto-detects a build at ../target/{release,debug}/xagit
  relative to the plugin directory.

Both editors load the same vim/plugin/xagit.vim (Vimscript); the correct
backend is chosen automatically via has('nvim'). No Lua file is needed.

==============================================================================
3. INSTALL						*xagit-install*

With a plugin manager, add the xagit repository and point it at the "vim"
subdirectory, e.g.:

  Vim (vim-plug / Vundle / dein / pathogen):
      Plug 'sigmaxue/xagit', { 'rtp': 'vim' }
      Plugin 'sigmaxue/xagit', { 'rtp': 'vim' }
      call dein#add('sigmaxue/xagit', {'rtp': 'vim'})
      git clone https://github.com/sigmaxue/xagit ~/.vim/bundle/xagit
        (pathogen picks up bundle/xagit/vim automatically)

  Neovim (lazy.nvim, in lua/plugins/xagit.lua):
      return {
        'sigmaxue/xagit',
        init = function()
          -- the plugin lives in the repo's vim/ dir, not the repo root
          vim.opt.rtp:append(vim.fn.stdpath('data') .. '/lazy/xagit/vim')
          vim.g.xagit_cmd = '/path/to/xagit/target/release/xagit' -- optional
          vim.cmd('runtime! plugin/xagit.vim')
        end,
      }
    Or set runtimepath directly (no manager):
      vim.opt.rtp:append('/path/to/xagit/vim')

  NOTE: the plugin file lives in the repository's vim/ subdirectory, not at
  the repository root. Plugin managers that only add the repo root need the
  rtp pointed at vim/ (vim-plug's 'rtp' option, or a manual rtp:append plus
  `runtime! plugin/xagit.vim`). Once vim/ is on 'runtimepath', both Vim and
  Neovim auto-load vim/plugin/xagit.vim on startup.

Or use Vim 8 packages (no manager). Vim adds each directory under
pack/*/start to 'runtimepath', so make the "vim" directory itself the
package by symlinking it: >
    mkdir -p ~/.vim/pack/xagit/start
    git clone https://github.com/sigmaxue/xagit ~/.vim/xagit-src
    ln -s ~/.vim/xagit-src/vim ~/.vim/pack/xagit/start/xagit
<
  Simplest: copy the contents of vim/ into ~/.vim/ (so that
  ~/.vim/plugin/xagit.vim and ~/.vim/doc/xagit.txt exist), or add: >
    set runtimepath+=/path/to/xagit/vim
<
Then generate the help tags once: >
    :helptags /path/to/xagit/vim/doc
<

4. USAGE						*xagit-usage*

    :Xagit                 open xagit in a floating window
    <leader>g              same (default mapping, if free)

The repository is taken from the current file's directory; xagit walks up
to the git toplevel via `git rev-parse --show-toplevel`, so opening a file
in a subdirectory works. Inside xagit:

    h / ?      dispatch (all commands)      s / u   stage / unstage
    c c        commit                        g       refresh
    q          back                          C-x C-c quit (closes the popup)

A second :Xagit while the popup is visible just re-focuses it (Vim allows
only one terminal popup at a time; the Neovim backend likewise reuses its
float). The command, <Plug>Xagit mapping and all |xagit-config| options are
identical on Vim and Neovim.

You can also remap via <Plug>: >
    nmap <leader>m <Plug>Xagit
<

==============================================================================
5. CONFIGURATION					*xagit-config*

All options are set before the plugin loads (in vimrc):

    *g:xagit_cmd*          string, default ''
        Full path to the xagit executable. Empty = search $PATH, then
        ../target/{release,debug}/xagit.

    *g:xagit_width*        float, default 0.9
    *g:xagit_height*       float, default 0.85
        Fraction of &columns / &lines used by the floating window.

    *g:xagit_min_width*    number, default 60
    *g:xagit_min_height*   number, default 18
        Lower bounds for small terminals.

    *g:xagit_dir*          string | Funcref, default ''
        Repository directory. '' = current file's directory. A Funcref is
        called with no arguments and returns a path, e.g.: >
            let g:xagit_dir = {-> FugitiveGitDir() =~ ''
                \ ? getcwd() : fnamemodify(FugitiveWorkTree(), ':p')}
<

Environment variables understood by xagit itself (set them in the shell
before starting Vim, or via |term_start()|):
    XAGIT_COLOR=truecolor|256|16|never
    XAGIT_THEME=dark|light
    XAGIT_ASCII=1
    NO_COLOR, TERM, COLORTERM

6. TROUBLESHOOTING					*xagit-troubleshooting*

"xagit executable not found" ~
    Set |g:xagit_cmd| to the absolute path, or install xagit into $PATH.

"needs Vim (+terminal +popupwin) or Neovim 0.5+" ~
    Your editor lacks these features. Vim needs a full build with +terminal
    and +popupwin; Neovim needs nvim_open_win()/termopen() (>= 0.5).
    Alternatively run :!xagit (suspends the editor) without a float.

Neovim: :Xagit does nothing / "not an editor command" ~
    The plugin is in the repo's vim/ dir. Make sure that dir is on
    'runtimepath' and the file was sourced (`runtime! plugin/xagit.vim`),
    e.g. via the lazy.nvim init() example in |xagit-install|.

Blank / garbled screen ~
    Ensure 'term' is correct and the terminal supports the color depth.
    Try XAGIT_COLOR=256 or XAGIT_ASCII=1.

C-s (search inside xagit) does nothing ~
    Some terminals use C-s for XOFF flow control. Run `stty -ixon` in the
    shell before starting Vim, or disable flow control in the terminal.

Only one popup allowed (E861) ~
    Vim only allows one terminal popup at a time; close the existing xagit
    popup (quit xagit with C-x C-c) before opening another. :Xagit always
    re-focuses the running float on both editors, so you should not hit this.
